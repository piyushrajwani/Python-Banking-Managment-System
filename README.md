# 🏦 Banking Management System

A console-based Banking Management System developed using
Python and MySQL.

This project demonstrates database connectivity, account
management, and basic banking operations.

## 🚀 Features

- Create a new bank account
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- Display all accounts
- Delete an account
- Store account information in MySQL

## 🛠️ Technologies Used

- Python
- MySQL
- MySQL Connector for Python
- VS Code

## ⚙️ Requirements

- Python 3
- MySQL Server 8.0 or compatible version
- MySQL Connector for Python

## 📥 Installation

### 1. Clone the repository

git clone YOUR_REPOSITORY_URL

### 2. Open the project folder

cd Banking-Management-System

### 3. Install dependencies

python -m pip install -r requirements.txt

### 4. Configure MySQL

Create the database and configure your MySQL
connection settings.

Do not upload your database password.

### 5. Run the application

python banking.py

## 🔒 Security Notice

This is an educational project and is not intended
for real banking transactions.

Passwords and PINs should never be stored in plain text.
Database credentials must be kept private.
